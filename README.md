# AI 论文版弗一把

AI 论文版弗一把是一个类 Wordle 的单人猜论文游戏。玩家输入论文标题、缩写或方法名，系统按一作国家/地区、发表年份、引用数快照、Venue、论文领域、Best Paper、时间检验奖等属性给出反馈。

## 在线体验

https://ai-fuyiba.a2450438770.workers.dev

当前站点通过 Cloudflare Workers 静态资源托管。`release/v0.2.0` 分支合并并推送到 `main` 后，Cloudflare 才会构建和更新这个线上地址；合并前该地址不代表已经运行 v0.2。

## v0.2 功能

- 内置 68 篇已启用的 AI 代表性论文。
- 四个题库分别为：经典综合 34 篇、视觉方向 30 篇、语言模型 30 篇、完整题库 68 篇。
- 移动端将每次猜测呈现为独立反馈卡，集中展示七项属性及高低方向提示。
- 对局数、胜率、当前连胜和最佳连胜保存在当前浏览器本地。
- 终局可复制由彩色方块组成的无剧透战绩，不包含答案或猜测标题。
- 应用为纯静态前端，不使用后端 API、数据库、账号或登录系统。

## 玩法

- 8 次机会内猜出目标论文即获胜。
- 绿色表示属性完全一致。
- 黄色表示属性接近，例如同宏观地区、年份接近、引用数接近、同类 venue 或相关领域。
- 年份和引用数会用箭头提示目标更高或更低。
- 可在经典综合、视觉方向、语言模型和完整题库之间切换；切换题库会开始新的一局。

## 本地开发

```bash
pnpm install
pnpm dev
```

默认访问 http://localhost:5173。

## 验证

```bash
pnpm install
pnpm validate:data
pnpm test
pnpm build
```

构建产物生成在 `dist/`，可直接部署为静态资源。

## 数据说明

论文数据位于 `src/data/papers.json`，当前包含 68 篇已启用论文。引用数来自 OpenAlex、Semantic Scholar 等公开索引或人工核对，并通过每条记录的 `citationCheckedAt` 保存检查日期；这些数据是有日期的数据快照，不是实时排名。
